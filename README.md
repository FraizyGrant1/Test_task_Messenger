# Messenger

## Локальный запуск

Требуется Node.js `^22.12.0`, `^24.0.0` или `>=26.0.0`, а также npm. Этот диапазон соответствует требованиям Vitest.

В корневой папке проекта откройте терминал и выполните команды ниже.

```bash
npm ci
npm run dev
```

Откройте адрес, который Vite выведет в терминале (обычно `http://127.0.0.1:5173`).

В приложении введите `idInstance` и `apiTokenInstance` Green API. После проверки авторизации укажите номер телефона аккаунта MAX, чтобы открыть чат.

## Возможности

- Проверка данных инстанса через Green API.
- Создание чата по номеру телефона с проверкой наличия аккаунта MAX.
- Просмотр имени и аватарки контакта.
- Отправка текстовых сообщений и получение входящих сообщений.
- Сохранение данных авторизации и текущего чата в `sessionStorage` текущей вкладки. (Хотя этого не было в требованиях. Но мне надоело в процессе разаботки каждый раз их вводить.)

## Команды

| Команда | Описание |
| --- | --- |
| `npm run dev` | Запустить сервер разработки |
| `npm run test` | Запустить unit-тесты Vitest |
| `npm run lint` | Проверить код ESLint |
| `npm run build` | Запустить тесты, проверку TypeScript и production-сборку |
| `npm run preview` | Локально просмотреть production-сборку |
